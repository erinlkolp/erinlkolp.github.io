Short note: posts can carry images now. Each post gets its own folder under
`src/assets/blog/<slug>/`, and a small `<PostImage>` wrapper renders them
inside an ASCII terminal frame so they stay on-brand.

<PostImage
  slug="backup-failure-learned-lesson"
  src="drobo_seems_okay.jpeg"
  alt="Drobo Looks Okay, But Has Secretly Failed"
  caption="Drobo Looks Okay, Right?"
/>

The wrapper hands the file to Astro's `<Image>` under the hood, so you get
responsive sizing and modern formats for free. Missing files fail the build
loudly — no silently broken `<img>` tags shipping to production.

<PostImage
  slug="backup-failure-learned-lesson"
  src="drobo_failed.jpeg"
  alt="Zero connectivity. It's borked and there is no fixing it."
  caption="Zero connectivity to the network and usb."
/>

To start a new post, copy `_template.mdx`, drop images in the matching
asset folder, and flip `draft: false` when ready.
